# Ứng viên tên mới cho Skill Hub

Ngày 2026-10-18. Tiếp theo [kiểm tra tên skillhub](researcher-261018-0611-name-check.md). Chưa đăng ký hay đổi gì.

## Đề xuất: Knackfold

- **Nghĩa.** *knack* là tài, ngón nghề (một skill); *fold* là chuồng giữ đàn, và "bring into the fold" là gom về một
  mối. Gộp lại: nơi gom và giữ các skill của mình. Khớp định vị "thư viện skill của riêng bạn, agent lấy khi cần".
- **Tình trạng (tra ngày 2026-10-18, chỉ tra registry và RDAP):**

| Nơi | Kết quả |
|---|---|
| GitHub repo trùng tên | 0 repo, 0 user |
| npm, PyPI, crates.io, Homebrew | Đều trống |
| knackfold.com, .dev, .io, .app | Đều trống theo RDAP |

- **Điểm yếu.** Chữ k đầu câm (đọc gần như "néc-phâu-đ"), người mới có thể gõ sai. Lệnh dài 9 ký tự. Chưa tra trademark
  (USPTO, EUIPO, WIPO).
- **Tagline gợi ý.** "Knackfold: your agent skills in one fold. Owned in Git, pulled over MCP."

## Nếu chọn đổi tên

Cần một plan riêng: đổi binary và module Go, tên MCP server, biến `SKILLHUB_*` và đường dẫn cấu hình (kèm đường
chuyển tiếp cho người đang dùng), repo GitHub (GitHub tự chuyển hướng link cũ), README, docs, video và logo.
Trước đó: tra trademark tay và mua domain.

## Vòng 4: con vật có hình ảnh tích cực (chủ project bỏ hình ảnh con quạ)

Tra 20 tên "skill + con vật". Loại: skillhawk (công cụ quét skill nguy hiểm cho agent), skillbee, skillcrane, skillkoi.

**Đề xuất: Skillmagpie** (chim khách). Chim khách nổi tiếng nhặt đồ sáng từ khắp nơi về tổ: khớp "gom skill từ mọi
repo về kho của mình". Ở Việt Nam, chim khách kêu là báo có khách, tin vui; chim khách cùng quạ bắc cầu Ô Thước.

| Nơi | Kết quả (2026-10-18) |
|---|---|
| GitHub repo và user `skillmagpie` | 0 |
| npm, PyPI, crates.io, Homebrew | Trống |
| skillmagpie.com, .dev, .io, .app | Trống theo RDAP |

Lưu ý: có một app agent tên "Magpie" với plugin quản lý skill (`voidrinz/skill-shelf-magpie-plugin`). Tên ghép
Skillmagpie vẫn khác, nhưng nên tìm hiểu thêm trước khi chốt.

Dự phòng, cũng 0 repo và registry trống, `.com` đã có chủ: Skillfalcon (chim ưng săn xong bay về tay chủ),
Skillsquirrel (sóc giấu hạt và nhớ chỗ), Skillelephant (voi không bao giờ quên). Skillheron, skilldolphin, skilloctopus
còn trống cả `.com`.
