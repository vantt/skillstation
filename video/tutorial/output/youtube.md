## Title

Skillstation tutorial: your agent skills in one Git repo (install, first skill, second computer)

## Description

Skillstation keeps your agent skills in one Git repository you own. Your agents connect to it over MCP and pull the
right skill, on demand, so there is nothing to copy into each project. You collect skills from anywhere, edit them,
and approve them before any agent gets them.

This video installs Skillstation, creates a hub, connects Claude Code, has the agent draft a first skill and publishes
it, edits it in the web UI, and then serves an agent on another computer.

Verified end to end with Claude Code. Codex and Gemini CLI connections are written but not yet verified end to end.
